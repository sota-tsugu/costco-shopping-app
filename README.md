# 我が家専用コストコ買い物リストアプリ

コストコ店内でカートを押しながら片手で使う、我が家専用の買い物リストアプリです。
合計金額と予算進捗を常時表示し、入力の手間をできる限りなくすことを目指しています。

詳しい企画コンセプトは [`costco_app_concept_v2.md`](./costco_app_concept_v2.md) を参照してください。

## 今のところの状態(2026年時点)

**フェーズ1-a・フェーズ1-bまで完了しています。** 予算を設定して買い物を始め、マイ定番棚から商品をタップしてカートに追加し、合計金額・予算の進捗を見ながら会計を完了する、という最小ループに加えて、単価の自動計算・過去の購入履歴と価格比較・事前買い物リストが使えます。

**フェーズ2として、パートナーとのリアルタイム共有機能に着手中です。** データの保存先をブラウザ内から Firebase(クラウド)に移行し、家族コード(合言葉)を共有した端末同士でリアルタイムに買い物リストやカートの中身が同期されるようにしています。

## 技術構成(なぜこの構成にしたか)

非エンジニアでも保守しやすく、かつ無料で運用できることを最優先に選びました。

| 項目 | 採用technology | 補足 |
|---|---|---|
| 画面表示 | React (Vite) + TypeScript | 見た目や動きを作る部分。Viteは開発中の画面確認を高速にしてくれる仕組み |
| データ保存 | Firebase Firestore | クラウド上のデータベース。無料枠(Sparkプラン)の範囲で利用し、パートナーとのリアルタイム共有を実現 |
| 認証 | Firebase Authentication(匿名認証)+ 家族コード | 個人のGoogleアカウントは使わず、家族内だけの合言葉でデータを共有する方式 |
| 見た目のスタイル | Tailwind CSS | 細かいCSSを毎回書かずに済むようにするツール |
| アイコン | Lucide | 無料で使えるアイコン集 |
| 状態管理 | Zustand | 画面の状態(カートの中身など)をシンプルに管理する仕組み |
| オフライン対応 | PWA(Service Worker)+ Firestoreのオフラインキャッシュ | 電波が不安定な店内でもアプリが起動・操作できるようにする仕組み |
| 保管・公開 | GitHub / GitHub Pages | コードの保管(バージョン管理)と、無料でのアプリ公開を兼ねる |

技術構成の比較検討の経緯(初期版)は `costco_app_concept_v2.md` の「4. 技術構成(決定)」に、フェーズ2でのFirebase移行の経緯は `CLAUDE.md` の「フェーズ2」節に記載しています。

## 開発の進め方

Claude Cowork(AIアシスタント)と一緒に、以下の順番で機能を作っていく計画です。

1. **フェーズ1-a**:合計金額表示・予算進捗・マイ定番棚・片手操作UI(まず動く最小限を2週間以内に)
2. **フェーズ1-b**:単価比較・購入履歴・事前買い物リストなど、MVPの拡充
3. **フェーズ1-c**:自動リスト生成(このアプリの核となる差別化機能)
4. **フェーズ2以降**:バーコードスキャン、音声入力、迷いログなど、体験を磨く機能

詳細は `costco_app_concept_v2.md` の「7. 機能一覧」「11. 開発の進め方」を参照してください。

## ローカルでの動かし方(開発者向け参考情報)

このアプリは基本的にGitHub Pagesで公開されたものをブラウザで開くだけで使えます。自分のパソコンで動かして確認したい場合は、以下のコマンドで起動できます。

```bash
npm install
npm run dev
```
