# 我が家専用コストコ買い物リストアプリ

コストコ店内でカートを押しながら片手で使う、我が家専用の買い物リストアプリです。
定番商品リストから今回買うものを選び、店内でカートに入れながら進行を管理し、
会計後は購入履歴・価格の推移をいつでも振り返れます。

現在の企画・設計方針は [`costco_app_concept_v3.md`](./costco_app_concept_v3.md) にまとめています。
2026年8月にそれまでの実装を一度白紙に戻し、ゼロベースで話し合った内容です
(経緯は [`CLAUDE.md`](./CLAUDE.md) の「白紙化(2026年8月)」の節を参照)。
初期の企画書 [`costco_app_concept_v2.md`](./costco_app_concept_v2.md) は参考用に残していますが、内容はv3に置き換わっています。

## 今できること(2026年8月時点)

3つの画面で構成しています。

**画面A(今回買うものリスト)**
- 定番商品リストから今回買うものを選び、予算を設定して見込み合計を確認(計画中)
- 買い物を始めると、検討中→会計待ちの状態を店内でその場で管理(買い物中)
- 買い物中から計画中の画面に戻ることも可能(カートの中身は保持される)
- 商品名の入力補助(costcotuu.com由来の商品名候補データベース、約3200件。漢字は1文字から候補表示)
- 「前回買ったものを反映」ボタンで、前回購入した商品を確認しながら一括選択
- 予算オーバー時は金額表示が赤くなり警告を表示

**画面B(カート)**
- 実際のカート写真の中に、商品数ぶん絵文字がランダムに積み上がっていくアニメーション(外部ライブラリ不使用、自作)
- バーコードスキャンで、計画リストに無かった商品もその場で追加(iPhoneのSafariはバーコード読み取り非対応のため[ZXing](https://github.com/zxing-js)を使用。過去のスキャン履歴・[Open Food Facts](https://world.openfoodfacts.org/)系の無料データベースから商品名を自動推測)
- 前回の合計金額との比較表示
- 「購入する」ボタンで会計完了(誤操作防止のため、会計ボタンはこの画面にのみ配置)

**画面C(購入履歴・レポート)**
- 年間利用額、買い物ごとの合計金額の推移グラフ、カテゴリ別の支出割合
- 購入日ごとに切り替えて見られる購入履歴一覧、商品名での絞り込み検索
- 商品ごとの単価比較(値上がり/値下がり)・購入頻度・単価推移グラフ(商品名タップで開く)
- 購入記録の訂正・削除(「購入する」ボタンの押し間違いなどに備えて)

グラフはいずれもChart.js等の外部ライブラリを使わず、インラインSVGを自前で組み立てて描いています。

家族コード(合言葉)を共有した端末同士は、これらのデータをすべてリアルタイムで共有します。

## 技術構成(なぜこの構成にしたか)

非エンジニアでも保守しやすく、かつ無料で運用できることを最優先に選びました。

| 項目 | 採用technology | 補足 |
|---|---|---|
| 画面表示 | React (Vite) + TypeScript | 見た目や動きを作る部分。Viteは開発中の画面確認を高速にしてくれる仕組み |
| データ保存 | Firebase Firestore | クラウド上のデータベース。無料枠(Sparkプラン)の範囲で利用し、家族間のリアルタイム共有を実現 |
| 認証 | Firebase Authentication(匿名認証)+ 家族コード | 個人のGoogleアカウントは使わず、家族内だけの合言葉でデータを共有する方式 |
| 見た目のスタイル | Tailwind CSS | 細かいCSSを毎回書かずに済むようにするツール。コストコのブランドカラーに近い配色を定義 |
| アイコン | Lucide | 無料で使えるアイコン集 |
| 状態管理 | Zustand | 定番商品・買い物トリップなどのデータをアプリ全体で共有する仕組み |
| バーコード読み取り | [@zxing/browser](https://github.com/zxing-js/browser) | iPhoneのSafariに無いバーコード読み取り機能を補う無料ライブラリ |
| 商品情報の自動取得 | [Open Food Facts](https://world.openfoodfacts.org/) / Open Products Facts / Open Beauty Facts | バーコードから商品名を推測する無料・APIキー不要のデータベース群 |
| オフライン対応 | PWA(Service Worker)+ Firestoreのオフラインキャッシュ | 電波が不安定な店内でもアプリが起動・操作できるようにする仕組み |
| 保管・公開 | GitHub / GitHub Pages | コードの保管(バージョン管理)と、無料でのアプリ公開を兼ねる |

## 開発の進め方

Claude Cowork(AIアシスタント)と一緒に、企画から実装まで進めています。
Claude Coworkの作業環境はインターネットに接続できないため、`npm install`の実行やGitHubへの
実際の送信(push)はできません。コードの作成・編集とローカルでのgitコミットまでをClaudeが行い、
GitHubへのpushはGitHub Desktop(無料アプリ)でSOTAさんが行う運用にしています。
`npm install`や`npm run build`が実際に動くかどうかは、pushした後のGitHub Actionsの実行結果で確認します。
詳しい制約・運用は [`CLAUDE.md`](./CLAUDE.md) を参照してください。

## ローカルでの動かし方(開発者向け参考情報)

このアプリは基本的にGitHub Pagesで公開されたものをブラウザで開くだけで使えます。自分のパソコンで動かして確認したい場合は、以下のコマンドで起動できます。

```bash
npm install
npm run dev
```

## 費用について

このプロジェクトは無料での運用を絶対条件としています。GitHub・GitHub Pages・Firebase(Sparkプラン)・
バーコード読み取り・商品情報取得の各ライブラリ/APIは、いずれも無料枠の範囲で利用しており、
現時点で有料のサービスは一切使用していません。
